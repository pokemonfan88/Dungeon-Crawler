# 🕯️ 烛照幽渊 (Candlelight Abyss)

> *"火尽人归，深处不留光。"*

暗黑奇幻风格的放置类地牢探索游戏。浏览器打开即玩，无需安装。

---

## 🎮 游戏简介

你是一位被深渊召唤的守望者。选择种族，握着火把，独自走进通往地心的裂缝。战斗自动进行，但生死抉择在你手中——何时释放技能、何时使用补给、何时在黑暗与安全间取舍。

**火把是你的生命线。越深越暗，回报越大，代价越高。**

## ✨ 功能特性

### 🏕️ 营地系统（9 标签）

| 标签 | 功能 |
|------|------|
| ⚔️ 整备 | 8 槽双塔装备 + 背包管理 + 磨损修理 |
| 📜 任务板 | 4 种类型 + 15 分钟限时 + 自动刷新 |
| 🛒 商店 | 6 种远征消耗品 |
| 🔨 铁匠铺 | 出售 / 鉴定 / 精炼材料兑换 / 13 配方打造 |
| 🕳️ 深渊之门 | 4 层级选择 + 渐进解锁 |
| ⛪ 教堂 | 随机祝福(3h冷却) + 恢复神智 |
| 📦 仓库 | 20→50 格扩容 + 材料堆叠 |
| 🔒 酒馆 | 280 尺解锁（队友招募预留） |
| ⚙️ 设置 | 统计 + 删除存档 |

### 🧬 种族系统（4 种族）

| 种族 | 被动 | 族技 | 解锁 |
|------|------|------|------|

| 🧝 精灵 | 事件奖励 ×1.3 | 林间步：强制触发事件 | 远征触发 3 事件 |
| 🐻 熊人 | 低神智攻击暴增 | 咆哮：恐惧怪物 | 神智<20% 击杀 |
| ⛏️ 矮人 | 铁匠费用 -30% | 山之心：8 秒减伤 50% | 累计打造 3 件 |

### 🛠️ 材料与制造体系

**怪物掉落 → 精炼 → 打造** 三级链：

- **8 种怪物专属材料**：每只怪掉特定材料（鼠牙/蝠翼/碎骨/石鳞片/腐泥精华/暗影之尘/灵魂残片/熔火之核）
- **T1 精炼材 12 种**：铁匠铺用怪物材料兑换（8 种单材 + 4 种配方混合）
- **13 个打造配方**：消耗精炼材，按品质递进（白→绿→蓝→紫→橙）
- **BOSS 装备 9 件**：独立于打造池，掉落需鉴定

### 🔥 远征系统

- 火把 + 神智双资源
- 5 个通用战斗技能 + 4 个种族技能
- 14 个探索事件（奇物/陷阱/叙事/休息点）
- 6 种远征消耗品
- 离线模拟（最多 4 小时）

## 🚀 快速开始

1. 下载 `烛照幽渊.html`（`node build.js` 构建）
2. 浏览器直接打开
3. 选择种族 → 营地 → 深渊之门 → 出征

存档保存在 `localStorage`，清缓存会丢失。

## 🏗️ 项目架构（v0.8.0+ 多文件开发）

```
src/
├── index.html           HTML 骨架 + CSS
└── js/
    ├── data.js           全部游戏数据定义
    ├── core.js           状态管理 / 存读档 / 属性计算
    ├── expedition.js     远征 / 战斗 / BOSS / 事件 / 技能
    ├── camp.js           营地渲染 + 交互
    ├── race.js           种族选择系统
    └── main.js           弹窗 / 事件绑定 / 启动

build.js                一键打包 → 烛照幽渊.html（单文件发布）
```
