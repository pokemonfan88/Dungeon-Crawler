# 🕯️ 烛照幽渊 (Candlelight Abyss)

> *"火尽人归，深处不留光。"*

一个暗黑奇幻风格的放置类地牢探索游戏。单文件 HTML，打开即玩，无需安装。

---

## 🎮 游戏简介

你是一位被深渊召唤的守望者。握着火把，独自走进通往地心的裂缝。战斗是自动的，但生死抉择在你手中——何时使用技能、何时消耗补给、何时在黑暗与安全之间做出选择。

**核心体验**：火把是你的生命线。越深入，黑暗越深，奖励越多，代价越大。

---

## ✨ 功能特性

### 🏕️ 营地系统（9 个功能标签）

| 标签 | 功能 |
|------|------|
| ⚔️ 整备 | 8 槽双塔装备（武器/头/躯干/手/腰/足/披风/圣物）+ 背包管理 + 修理 |
| 📜 任务板 | 4 种任务类型 + 15 分钟限时 + 自动刷新 |
| 🛒 商店 | 6 种远征消耗品（火把油/绷带/镇静剂/解毒剂/圣水/火药瓶） |
| 🔨 铁匠铺 | 出售物品 / 鉴定装备 / 12 种打造配方 |
| 🕳️ 深渊之门 | 4 层级深渊选择 + 渐进解锁 + 出征 |
| ⛪ 教堂 | 随机祝福（3h 冷却）+ 付费恢复神智 |
| 📦 仓库 | 20→50 格渐进扩容 + 材料堆叠 |
| 🔒 酒馆 | 到达 280 尺解锁（未来队友招募） |
| ⚙️ 设置 | 游戏统计 + 删除存档 |

### 🧬 种族系统

| 种族 | 被动 | 族技 | 解锁条件 |
|------|------|------|----------|
| 👤 人类 | 韧性：远征结束恢复 25% 神智 | 振奋：清除减益 | 初始 |
| 🧝 精灵 | 深邃感知：事件奖励 ×1.3 | 林间步：强制触发事件 | 一次远征触发 3 个事件 |
| 🐻 熊人 | 血怒：低神智时攻击暴增 | 咆哮：恐惧怪物 | 神智 <20% 时击杀怪物 |
| ⛏️ 矮人 | 锻炉血脉：铁匠费用 -30% | 山之心：8 秒减伤 50% | 累计打造 3 件 |

### 🔥 远征系统

- **火把**：计时器 + 难度调节器，越暗越危险也越多回报
- **神智**：低于阈值时触发幻觉、影响战斗、10% 概率"顿悟"
- **14 个探索事件**：奇物互动 / 陷阱 / 叙事碎片 / 休息点
- **5 个主动技能**：猛击 / 格挡 / 点燃投掷 / 凝神屏息 / 孤注一掷
- **6 种消耗品**：远征中使用，战斗/探索均可
- **离线模拟**：关闭页面后英雄继续战斗（最多 4 小时）

### 📊 数据规模

```
40 件装备模板 · 14 个探索事件 · 12 个打造配方 · 12 个任务
6 种消耗品 · 5 个通用技能 · 4 个种族技能 · 6 种教堂祝福
8 种稀有遗物 · 4 层深渊 · ~2200 行代码
```

## 🚀 快速开始

1. 下载 `烛照幽渊_v2.html`
2. 用浏览器直接打开
3. 选择种族 → 进入营地 → 整备 → 深渊之门 → 出征

存档保存在浏览器 `localStorage` 中，清缓存会丢失。

## 🗺️ 深渊层级

| 层级 | 深度范围 | 解锁条件 | 解锁奖励 |
|------|----------|----------|----------|
| 浅层回廊 | 0-70 尺 | 初始 | — |
| 中层甬道 | 70-160 尺 | 到达 70 尺 | 头部+腰部槽位 |
| 深层墓室 | 160-280 尺 | 到达 160 尺 | 披风槽位 |
| 绝渊回廊 | 280+ 尺 | 到达 280 尺 | 圣物槽位 + 酒馆 |

## 🏗️ 技术架构

```
单文件 SPA — HTML/CSS/JS 内联
无外部依赖 · 无构建工具 · 零配置
localStorage 存档 · 离线友好
```

```
数据流：freshState() → load() → S 全局状态
       → calcHeroStats() / stepTick() / render*()
       → save() → localStorage
```
